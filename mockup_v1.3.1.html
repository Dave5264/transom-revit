Export schedules → spreadsheet

Check schedules to export — each becomes a sheet (CSV writes one file per schedule).

In the exported file: grey cells can't be imported (read-only or driven by the family/type); green cells are bulk edits (a type parameter or group header — changing one updates every element it covers); blue cells are grouped elements' project parameters — Transom applies these by enabling “vary by group instance”; yellow cells are grouped elements' built-in parameters, applied via Claude-assist (they appear only when Claude-assist is enabled — otherwise a muted grey). Other cells edit one element.
